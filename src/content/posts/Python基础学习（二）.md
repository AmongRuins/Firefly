## 程序的三大流程

1. **顺序结构**：按照代码的书写顺序，`从上到下依次执行每一条语句`，是程序最基本的执行流程。

2. **判断结构（分支结构）**：依据给定的条件表达式进行判定，根据结果（True/False）`选择性执行对应分支的代码`，实现逻辑分流。

3. **循环结构**：在满足特定条件时，`重复执行某一段代码块`，直到条件不成立或触发终止机制为止，避免冗余代码。

### 判断结构

Python 中的判断语句主要通过 `if、elif、else` 三个关键字实现，用于根据条件的真假（True/False）来控制程序的执行流向。

```python
if 判断条件:
    # 条件成立时执行的代码块
elif 判断条件:
    # 上述条件不成立，但当前条件成立时执行的代码块
else:
    # 上述所有判断均不成立时执行的代码块
```

判断语句并`不强制要求写全三者`，可根据实际逻辑灵活搭配：

- **单 if 型**：仅在条件满足时执行特定操作，不满足则跳过。

- **if-else 型**：非此即彼的二元选择，条件成立走一条路，不成立走另一条。

- **if-elif 型**：用于多重条件的依次判断，但不处理 “所有条件都不满足” 的情况。

支持在一个 if 或 else 代码块内部，再嵌入下一层 if 判断，形成逻辑递进。即：先通过第一层判断，再根据结果决定是否进行下一层更细致的判断。

### 循环结构

while 循环的关键在于`循环控制变量的合理设置与更新`：

1. **初始化**：在循环开始前，需先定义并初始化一个控制循环的变量（如`计数器`）。

2. **变量更新**：在循环体内部，必须对`该控制变量进行更新`（如递增、递减或其他改变条件的操作），使 “判断条件” 最终趋于不成立，从而让循环正常结束。

3. **避免无限循环**：若`忘记更新控制变量`，或更新逻辑无法让条件变为 False，程序将陷入无限循环（死循环），需特别注意。

```python
while 判断条件:
    # 条件成立时重复执行的循环体代码
```

---

for 循环的主要作用是`依次遍历可迭代对象（如列表、字符串、元组、字典等）`中的每一个元素：每遍历到一个元素，就将其赋值给 变量名，并执行一次循环体代码，直到所有元素遍历完毕，循环自动结束。

```python
for 变量名 in 可迭代对象:
    # 每次循环重复执行的代码块
```

`break` 表示该循环结束；`continue` 表示本次循环结束，开始下一次循环。

## 补充：随机数

1. 使用随机数模块（import random）的方法可以随机在指定范围内产生随机整数：`random.randint(a,b)`，产生 `[a,b]` 之间的随机整数。

2. `range(a,b,step)`：`step（步长）` 可省略。表示获取 `[a,b）`之间的整数，如果`只有一个参数，默认从 0 开始`。

## 字符串

容器是 Python 中的高级数据类型，可`一次性存储多个数据`。常见容器类型包括：`字符串（str）、列表（list）、元组（tuple）、字典（dict）`。

字符串是由`引号`包裹的字符序列，支持多种便捷操作。

- 可用单引号 `''`、双引号 `""` 或 三引号 `'''"""` 包裹内容。同时引号也可以`嵌套使用`，例如：`"'我是字符串'"`。

- 在字符串前加 `r` 前缀，即为`原生字符串`。其特点是：字符串内的`转义字符（如 \n、\t）不会被解析`，会原样输出，常用于文件路径、正则表达式等场景。

### 索引

字符串支持通过索引访问单个字符，索引分为两种：

- 正向索引：从左到右，以 `0、1、2...` 依次编号。

- 负向索引：从右到左，以 `-1、-2、-3...` 依次编号。

通过 `len(字符串)` 可快速获取字符串的字符个数。示例：`len("Python")` 返回 6。

### 常见方法

1. 切片：用于从字符串中提取多个字符，语法为：

```python
字符串[start:end:step]
```

- `start`：开始位置的下标（包含该位置），默认从 `0` 开始。

- `end`：结束位置的下标（不包含该位置），默认到字符串末尾。

- `step`：步长，即每次跳过的字符数，默认值为 `1`。

- 示例：`"Python"[1:5:2]` 提取下标 `1、3` 的字符，结果为 `"yh"`。

- 特殊用法：反转字符串 `[::-1]`，例如 `"Python"[::-1]` 返回 `"nohtyP"`。

---

2. 查找：用于查找子字符串是否存在，语法为：

```python
字符串.find(sub_str, start, end)
```

- `sub_str`：要查找的目标子字符串。

- `start`：查找的起始位置，默认 `0`。

- `end`：查找的结束位置，默认到`字符串末尾`。

- 返回值：若找到，返回子字符串`首次`出现的起始下标；若未找到，返回 -1。

---

3. 替换：将字符串中的旧子串替换为新子串，语法为：

```python
字符串.replace(old_str, new_str, count)
```

- `old_str`：需要被替换的旧子串。

- `new_str`：替换后的新子串。

- `count`：替换的次数（可选，默认替换所有匹配项）。

- 注意：字符串是不可变类型，`replace() 会返回一个新字符串`，原字符串不会改变。

---

4. 拆分：将字符串按指定分隔符拆分为列表，语法为：

```python
字符串.split(sep, maxsplit)
```

- `sep`：分隔符（可选），默认按`空白字符（空格、换行符 \n、制表符 \t 等）`拆分。

- `maxsplit`：最大拆分次数（可选），默认 `-1`（全部分割）。

- 特殊用法：若需省略 sep 但指定拆分次数，可写为 `split(maxsplit=n)`（n 为次数）。

---

5. 拼接：将字符串作为 “连接符”，插入列表的元素之间，形成新字符串，语法为：

```python
连接符字符串.join(列表)
```

- 注意：列表中的元素必须`全为字符串类型`，否则会报错。

- 示例：`"-".join(["a", "b", "c"])` 返回 `"a-b-c"`。

## 列表

列表（list）是 Python 中`使用极为频繁`的容器类型，可存储`任意类型`的数据，在其他编程语言中常被称为 “数组”。

经常使用方括号 `[]` 直接定义列表，但也可以通过 `list()` 函数定义（`使用频率较低`）。

列表的下标（索引）和切片操作与字符串类似：`通过下标可获取单个元素`；`通过切片可截取列表，生成一个新列表`。

列表推导式是 Python 中高效创建列表的语法糖，核心结构为：`变量名 = [表达式 for 变量 in 可迭代对象]`。执行逻辑：每循环一次，将「表达式」的计算结果追加到新列表中。
```python
my_list = ["hello" for i in range(5)]
```

### 查找

1. 查找元素位置

    - 语法：`列表.index(数据, start, end)`

    - 从下标 `start` 位置开始查找，至 `end` 位置结束；

    - 若找到则返回该元素的下标，未找到则报错。

2. 判断元素是否存在：`数据 in 容器`，存在返回 True，反之返回 False。

3. 统计元素出现次数：`列表.count(数据)`，返回该数据在列表中出现的次数。

### 添加

1. 尾部添加元素（常用）：`列表.append(数据)`，将数据直接添加到`列表尾部`。

2. 指定位置插入元素（很少用）：`列表.insert(下标, 数据)`，若该下标处已有数据，原有数据会自动后移，此操作需移动后续元素，`性能消耗较大`。

3. 合并两个列表：`列表.extend(另一个列表)`，将另一个列表中的数据逐个添加到`当前列表的尾部`。

以上三种添加方法均会`直接修改原有列表`，且返回值为 `None`（表示无数据可接收）。

### 修改

列表是`可变类型`，支持`通过下标直接修改指定位置的元素`；而字符串是不可变类型，无法通过下标修改单个字符。

语法：`列表名[下标] = 新数据`

### 删除

列表执行删除操作后，`后续元素会自动向前移动`，以填补被删除元素的位置。

- **列表.pop(下标)**：根据下标删除指定位置的元素。若省略下标，默认删除列表末尾元素；方法会返回被删除的数据值，可直接接收使用。

- **列表.remove(数据)**：根据数据值删除列表中第一个匹配的元素。该方法无返回值（返回 None）。

- **列表.clear()**：清空列表中的所有元素，执行后列表变为空列表。

### 其他方法

- **列表反转**：`列表.reverse()`直接原地反转列表元素的顺序，该方法无返回值（返回 `None`）。

- **列表复制**：`列表.copy()`生成并返回列表的一个浅拷贝副本，原列表不受影响。

- **列表排序**：`列表.sort()`直接原地对列表元素排序，默认按升序排列；若添加参数 `reverse=True`，则改为降序排列，该方法无返回值（返回 None）。

集合是 Python 内置的无序可变容器，核心特性是`元素的唯一性`，天然不允许重复元素存在，因此常被用于`快速实现列表去重`。
> 缺点在于会对里面元素`进行排序`

## 元组

元组可以`存储任意类型、多个数据`，`定义后数据不可修改`，常用于函数传参和返回值。

元组只有一个数据时，必须在末尾加逗号，否则 Python 不会识别为元组。示例：`变量名 = (1,)`

元组由于不能修改数据，故只能进行查询操作。该操作与列表的一致。

- 通过`下标、切片`获取指定位置数据

- 通过 `index()` 方法查找数据的下标位置

- 通过 `count()` 方法统计数据出现次数

- 使用 `in` 关键字判断数据是否存在

## 字典

字典是由 **键值对（key-value）** 组成的可变映射容器，可存储任意类型的数据，是 Python 中最常用的数据结构之一。

### 键（key）的核心规则

键的常用类型为字符串，也可使用数字等`不可变类型`，`禁止使用列表等可变类型`作为键。

字典中的键具备`唯一性`，不可重复；若出现重复键，`后定义的键值对会直接覆盖原有值`。

字典无法直接整体转为字符串、列表、元组的原生内容形态，但可通过内置方法提取键、值或键值对，完成对应类型的转换（如`list(字典.items())`、`tuple(字典.keys())`等）。

### 增改操作

核心语法：`字典[键] = 值`

- 当指定的`键已存在`时，执行修改操作，覆盖该键对应的原值；

- 当指定的`键不存在`时，执行新增操作，向字典中添加该键值对。

### 删除操作

1. `del 字典[键]`：通过键精准删除指定的键值对；

2. `字典.clear()`：清空字典内所有键值对，保留空字典，用法与列表、元组的 clear 方法一致。

### 查询操作

1. 方括号直接取值：`字典[键]`，可获取键对应的值，`缺点是若键不存在，程序会直接抛出 KeyError 报错`。

2. get () 方法取值（优先推荐）：`字典.get(键, 默认值)`

    - 键存在时，返回该键对应的值；

    - 键不存在时，返回指定的默认值；不设置默认值时，默认返回None，不会触发程序报错。

### 字典遍历操作

1. 遍历所有键：`for 临时变量 in 字典.keys():`

2. 遍历所有值：`for 临时变量 in 字典.values():`

3. 遍历所有键值对：`for 键变量, 值变量 in 字典.items():`

### 补充

字符串、列表、元组均支持`加法`和`乘法`基础运算：

- 加法运算：同类型容器相加，会将两个容器的内容拼接合并，生成新的同类型容器；

- 乘法运算：`容器 * 数字N`，会将容器内的内容重复 N 次，生成新的同类型容器。
