## Web 测试

主要测试 **网页 / 网站 / Web 系统** 是否正常、好用、稳定、安全。

主要以下包含几部分：
1. **功能测试**（最重要）：测网站`能不能正常用`
    - 页面跳转、按钮、输入框、表单
    - 增删改查、登录注册、权限
    - 业务流程是否走得通
    - 异常输入、边界值

2. **界面 / UI 测试**：测`好不好看、排版对不对`
    - 样式、颜色、字体、对齐
    - 图片、图标、弹窗
    - 不同浏览器显示是否一致

3. **兼容性测试**：测在`各种环境能不能正常跑`
    - 浏览器兼容：Chrome、Edge、Firefox
    - 系统兼容：Windows、Mac
    - 分辨率兼容：电脑、平板、手机

4. **性能测试**：测`快不快、扛不扛得住`
    - 响应时间
    - 并发用户数
    - 压力测试、负载测试
    - 页面加载速度

5. 安全测试：测`有没有漏洞、危不危险`
    - SQL 注入
    - XSS 跨站脚本
    - 越权访问
    - 密码安全、HTTPS

6. 易用性测试（用户体验）
    - 测好不好操作
    - 是否简单易懂
    - 提示是否清晰
    - 导航是否方便

7. 接口测试（现在必考）
    - 测前后端交互的数据对不对
    - 请求参数、返回值
    - 状态码、异常情况
    - 加密、鉴权

8. 自动化测试（进阶）
    - 用代码跑测试，代替手工
    - 网页自动化（Selenium）
    - 接口自动化
    - 加密、鉴权

Web 测试和 App 测试区别（面试常问）
    - Web：浏览器、不用安装、重点**兼容浏览器**
    - App：要安装、升级、适配手机、耗电、弱网

Web 常见缺陷举例：`点按钮没反应`、`页面乱版、错位`、`在某个浏览器打不开`、`数据提交错误`、`页面加载很慢`、`可以绕过登录访问页面`。

## 界面 / UI 测试

UI 测试简单说：看**页面长得对不对、好不好看、规不规范，不看功能**，只看 “样子和布局”。

### UI 测试测什么

1. 布局 & 对齐
    - 按钮、输入框、文字是否对齐
    - 间距是否统一、有没有错位、重叠
    - 弹窗居中不居中

2. 样式 & 颜色
    - 字体、字号、加粗是否统一
    - 主色调、按钮颜色是否按原型来
    - 报错文字是不是红色、提示色对不对

3. 图片 & 图标
    - 图片不模糊、不拉伸、不缺失
    - 图标显示正常、大小一致

4. 文字内容
    - 有没有错别字、乱码
    - 文案和需求一致
    - 提示语完整、通顺

5. 自适应 / 分辨率
    - 拉大、缩小浏览器会不会乱版
    - 不同屏幕分辨率会不会变形

6. 浏览器展示一致（属于 UI + 兼容）
    - Chrome / Edge 打开，样式是不是一样
    - 有没有有的浏览器好看、有的浏览器乱掉

### UI 测试对照什么测？

只对照三样：原型图（Figma / PS）、需求文档、设计规范

### 常见 UI Bug（工作最常见）

- 文字偏移、按钮错位
- 两个页面字体不一样
- 图片裂开、拉伸
- 浏览器打开样式不一样
- 弹窗不居中、遮挡内容
- 换行错乱、空白太多 / 太少

### 总结

UI 界面测试主要测试**页面布局、样式、颜色、字体、图片、文案、对齐、自适应和浏览器展示效果**，对照设计图检查是否美观、统一、符合规范。

## 功能测试

看**功能能不能用、流程通不通、数据对不对、异常扛不扛得住**。

总体来说，功能测试主要验证**系统业务流程、页面元素、增删改查、表单校验、权限、边界值、异常场景**是否符合需求，保证软件能用、做得对。

业务流程，一般会涉及到多个模块的数据，所以在对业务流程测试时，首先要保证单个模块功能的正确性。其次就要对各个模块间传递的数据进行测试，这往往是容易出现问题的地方，测试时一定要设计**不同的数据**进行测试。

### 功能测试测什么（照着测就行）

1. 基础元素测试
    - 按钮：点击有没有反应
    - 输入框：正常输入、清空、复制粘贴
    - 下拉框、单选、复选、日期框
    - 链接跳转是否正确

2. 业务流程测试（重点）
    - 正常流程能不能走完
    - 例如：登录 → 查询 → 新增 → 修改 → 删除 → 导出

3. 增、删、改、查（CRUD）
    - 新增：能不能保存、数据是否入库
    - 查询：能不能查到、模糊查询、精确查询
    - 修改：改完是否生效
    - 删除：删完是否消失、有没有提示

4. 登录 & 权限测试
    - 正常登录、错误密码登录
    - 记住密码、退出登录
    - 不同权限用户看到不同菜单（普通用户 / 管理员）

5. 表单 & 校验规则
    - 不能为空
    - 手机号、邮箱格式
    - 长度限制、特殊符号

6. 边界值测试
    - 输入最长、最短
    - 数字最大、最小
    - 临界点

7. 异常场景 / 反向测试
    - 乱输数据
    - 重复提交
    - 断网、刷新页面
    - 返回上一步

### 几个常见功能 Bug
- 点按钮没反应
- 提交表单没提示、保存失败
- 数据修改后没变
- 可以重复提交订单
- 不填内容也能提交
- 普通用户能看到管理员页面（越权）
