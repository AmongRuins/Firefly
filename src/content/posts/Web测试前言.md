**C/S（Client/Server）：客户端 + 服务器**：需要**装软件**才能用（QQ 客户端、抖音 APP、王者荣耀、钉钉客户端、财务软件）

**B/S（Browser/Server）：浏览器 + 服务器**：不用装软件，**打开浏览器**就能用（百度、学校教务系统、公司后台管理系统）

两者详细对比：
| 对比点  | C/S 架构              | B/S 架构       |
|------|---------------------|--------------|
| 运行方式 | 安装客户端 APP           | 浏览器直接访问      |
| 维护升级 | 麻烦，每人都要更新客户端        | 简单，只更新服务器    |
| 硬件要求 | 高，吃电脑配置             | 低，只需要浏览器     |
| 跨平台  | 差（Windows/Mac 要分开做） | 好，有浏览器就能用    |
| 安全性  | 相对高                 | 相对低（网页容易被攻击） |
| 体验感  | 好，界面流畅、功能多          | 一般，受浏览器限制    |
| 网络要求 | 可离线使用部分功能           | 必须联网         |

两者在软件测试里的区别（重点）
1. 测 C/S
    - 要测兼容性：不同系统（Win7/10/11）、不同分辨率
    - 要测安装、卸载、升级、断点更新
    - 要测离线功能、本地缓存

2. 测 B/S
    - 要测浏览器兼容性（Chrome、Edge、Firefox）
    - 要测 http/https 请求、cookie、session
    - 不用测安装，重点测页面、接口、权限
