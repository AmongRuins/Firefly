Python 主要有`三种`流程控制结构，用于控制代码的执行顺序。

## 顺序结构

`最基本的流程结构`，代码按照从上到下的顺序依次执行，没有任何判断或跳转。

```python
print("第一步")
print("第二步")
print("第三步")
```

## 选择结构（分支结构）

根据条件判断的结果，选择执行不同的代码块。Python 提供了 `if`、`if-else`、`if-elif-else` 三种形式。

1. 单分支 if：当条件为 True 时执行代码块，否则跳过。
    ```python
    age = 18
    if age >= 18:
        print("已成年")
    ```

2. 双分支 if-else：条件为 True 执行 if 块，否则执行 else 块。
    ```python
    age = 17
    if age >= 18:
        print("已成年")
    else:
        print("未成年")
    ```

3. 多分支 if-elif-else：依次判断多个条件，执行第一个为 True 的代码块；若都不满足，则执行 else 块。
    ```python
    score = 85
    if score >= 90:
        print("优秀")
    elif score >= 80:
        print("良好")
    elif score >= 60:
        print("及格")
    else:
        print("不及格")
    ```

## 循环结构

让代码块`重复执行`多次，Python 提供 `for` 和 `while` 两种循环。

1. for 循环：用于遍历可迭代对象（如列表、字符串、range）。
    ```python
    # 遍历列表
    fruits = ["apple", "banana", "cherry"]
    for fruit in fruits:
        print(fruit)

    # 使用 range(start,end,step) 生成数字序列 [start , end)，步长不写默认为 1
    for i in range(5):  # 0 到 4
        print(i)
    ```

2. while 循环：只要条件为 True，就会重复执行代码块。
    ```python
    count = 0
    while count < 5:
        print(count)
        count += 1  # 必须更新条件，否则会无限循环
    ```

3. 循环控制关键字
- `break`：立即终止整个循环。
    ```python
    for i in range(10):
        if i == 5:
            break
        print(i)  # 输出 0-4
    ```

- `continue`：跳过当前循环的剩余代码，进入下一次循环。
    ```python
    for i in range(5):
        if i == 2:
            continue
        print(i)  # 输出 0,1,3,4
    ```

- `else（循环的子句）`：当循环正常结束（未被 break 中断）时执行。
    ```python
    for i in range(3):
        print(i)
    else:
        print("循环正常结束")
    ```


### 补充：随机数

使用随机数模块（import random）的方法可以随机在指定范围内产生随机整数：`random.randint(a,b)`，产生 `[a,b]` 之间的随机整数。

## 运算符

### 算术运算符

| **运算符** | **运算符名称** | **核心功能**           | **关键备注**                     |
|-----|-------|----------------|--------------------------|
| `()`  | 小括号   | 提升运算优先级        | 优先级最高，可嵌套使用，优先执行括号内的运算   |
| `**`  | 幂运算符  | 计算数值的幂次方       | 优先级仅次于小括号，可实现平方、立方等运算    |
| `*`   | 乘法运算符 | 计算两个数值的乘积      | 属于乘除商余运算组，同级别从左到右执行      |
| `/`  | 除法运算符 | 计算两个数值的商       | 核心特性：无论是否整除，运算结果始终为浮点型   |
| `//`  | 整除运算符 | 计算商的整数部分（向下取整） | 仅保留整数位，舍弃小数部分，负数遵循向下取整规则 |
| `%`   | 取余运算符 | 计算两数相除后的余数     | 常用于判断奇偶性、循环周期等场景         |
| `+`   | 加法运算符 | 计算两个数值的和       | 优先级最低的运算组，也可用于字符串拼接      |
| `-`   | 减法运算符 | 计算两个数值的差       | 优先级最低的运算组，也可用于表示负数       |

- **整除的向下取整**：对负数也生效，如 `-5 // 2 = -3`（而非 -2）。

- **取模的符号规则**：结果符号与除数一致，如 `-5 % 2 = 1`，`5 % -2 = -1`。

### 比较（关系）运算符

| **运算符** | **运算符名称** | **核心功能**          | **结果说明**                                        |
|---------|-----------|-------------------|-------------------------------------------------|
| **==**      | 等于运算符     | 判断左右两边的值是否完全相等    | 所有比较运算符的运算结果仅为布尔值 True/False |
| **!=**      | 不等于运算符    | 判断左右两边的值是否不相等     | 条件成立返回 True，不成立返回 False                         |
| **>**       | 大于运算符     | 判断左边的值是否大于右边的值    | 条件成立返回 True，不成立返回 False                         |
| **<**       | 小于运算符     | 判断左边的值是否小于右边的值    | 条件成立返回 True，不成立返回 False                         |
| **>=**      | 大于等于运算符   | 判断左边的值是否大于或等于右边的值 | 满足大于 / 等于任一条件，即返回 True                          |
| **<=**      | 小于等于运算符   | 判断左边的值是否小于或等于右边的值 | 满足小于 / 等于任一条件，即返回 True                          |

链式比较：Python 支持 `a < b < c` 形式的链式比较，等价于 `a < b and b < c`。

### 逻辑运算符

| **运算符** | **名称 / 功能描述**                                         | **结果** |
|---------|-------------------------------------------------------|--------|
| and     | 逻辑 “与”：仅当两侧表达式均为 True时，结果才为 True；否则返回 False           | False  |
| or      | 逻辑 “或”：只要两侧表达式有一个为 True，结果就为 True；若全为 False 则返回 False | True   |
| not     | 逻辑 “非”：对单个表达式结果取反，True 变 False，False 变 True           | False  |

逻辑运算符会从左到右依次判断，`一旦能确定结果，就立即停止执行后续代码`，不会计算右边的表达式：
```python
# 短路示例：右边的 10/0 不会执行，不会报错
a = 0 and 10/0  # a = 0（左边为False，直接返回）
b = 5 or 10/0   # b = 5（左边为True，直接返回）
```

### 赋值运算符

| **运算符** | **名称 / 功能描述**            | **示例（等价于）**        |
|---------|--------------------------|--------------------|
| =       | 基本赋值：将右侧表达式的值直接赋给左侧变量    | a = 10             |
| +=      | 加后赋值：左侧变量与右侧值相加，结果赋给左侧变量 | a += 3 → a = a + 3 |
| -=      | 减后赋值：左侧变量减去右侧值，结果赋给左侧变量  | a -= 2 → a = a - 2 |
| *=      | 乘后赋值：左侧变量与右侧值相乘，结果赋给左侧变量 | a *= 2 → a = a * 2 |
| /=      | 除后赋值：左侧变量除以右侧值，结果赋给左侧变量  | a /= 2 → a = a / 2 |

复合赋值对`可变对象`（如列表）是「原地修改」，不会创建新对象；对`不可变对象`（如整数）会创建新对象。
