变量是 Python 中最基础的核心概念，`本质是绑定内存中数据对象的「标签 / 引用」`，用于存储和操作程序运行时的数据。

### 变量命名规则

Python 中变量需`强制`遵守一下语法规则（违反会直接报错）：

1. 变量名只能由`大小写英文字母、数字、下划线 _ `组成，不能包含空格、特殊符号（如 @、#、$）。

2. 不能`以数字开头`。例如 123name 非法，name123 合法。

3. 不能使用 Python 的`关键字 / 保留字`（如 if、for、def、class 等）。

4. 严格`区分大小写`。例如 Name 和 name 是两个完全独立的变量。

---

以下是行业`通用命名规范`（PEP8 标准，推荐遵守） 

| **变量类型** | **命名规则**            | **示例**                      |
|----------|---------------------|-----------------------------|
| **普通变量** | 全小写，多单词用下划线分隔（蛇形命名） | `user_name、age、order_total`   |
| **私有变量** | 单下划线开头，仅模块 / 类内部使用  | `_private_data、_inner_count`  |
| **常量**   | 全大写，多单词用下划线分隔       | `MAX_SIZE、PI、DEFAULT_TIMEOUT` |

- 禁止使用`拼音`、`无意义的单字母`（循环变量 i/j 除外）、`模糊命名`（如 a1、temp2）。

- 禁止覆盖 `Python 内置函数 / 对象`（如list、str、len、print），否则会导致原函数无法使用。

### 变量赋值方式

Python 赋值的核心是「`先创建对象，再给变量绑定引用`」，支持多种灵活的赋值语法，大幅简化代码。

1. 基础赋值：最常用的赋值方式，格式为 `变量名 = 数据值`
    ```python
    name = "Python"  # 字符串
    age = 25         # 整数
    is_valid = True  # 布尔值
    ```

2. 链式赋值：多个变量同时绑定同一个对象，适合给多个变量赋相同初始值
    ```python
    # 等价于 c=100; b=c; a=b，三个变量都指向同一个整数对象100
    a = b = c = 100
    ```

3. 并行赋值：一行代码给多个变量同时赋不同的值，最经典的用法是`无需中间变量交换两个变量的值`
    ```python
    # 多变量同时赋值
    x, y = 10, 20
    print(x, y)  # 输出 10 20

    # 快速交换变量（Python独有语法，无需临时变量）
    x, y = y, x
    print(x, y)  # 输出 20 10
    ```

4. 解包赋值：将可迭代对象（列表、元组、字符串等）的元素，批量赋值给多个变量，支持剩余元素捕获
    ```python
    # 基础解包
    a, b, c = [1, 2, 3]
    name, age = ("张三", 25)
    print(a, b, c)  # 1 2 3
    print(name, age)  # 张三 25
    ```

上面的赋值方式都`没有给变量声明数据类型`，这是因为 Python 是`动态类型语言`，核心特点是：

- 变量无需提前声明数据类型，`类型由它当前绑定的对象决定`，而非变量本身。

- 同一个变量`可以随时绑定不同类型的对象`，类型可动态改变。

```python
var = 10          # 绑定int对象，var此时为整数类型
var = "hello"     # 重新绑定str对象，var变为字符串类型
var = [1, 2, 3]   # 重新绑定list对象，var变为列表类型
```

#### 补充

Python有两个常用内置函数，用于确认变量当前绑定的对象类型：

- **type(变量)**：查看变量当前绑定对象的具体类型
    ```python
    a = 3.14
    print(type(a))  # 输出 <class 'float'>
    ```

- **isinstance(变量, 类型)**：判断变量是否属于指定类型（支持`继承判断`，比 type 更严谨）
    ```python
    b = [1,2,3]
    print(isinstance(b, list))  # 输出 True
    ```

### 变量作用域

变量的作用域，指变量在程序中可以被访问的有效范围。Python 遵循 `LEGB` 作用域查找规则，按照「从内到外」的顺序查找变量：

| **作用域** | **全称**          | **说明**                                       |
|---------|-----------------|----------------------------------------------|
| **L**   | Local（局部作用域）    | 函数 / 类方法内部定义的变量，仅在函数内部生效，函数执行结束后自动销毁         |
| **E**   | Enclosed（嵌套作用域） | 嵌套函数中，外层函数的作用域，闭包场景核心使用                      |
| **G**   | Global（全局作用域）   | py 文件顶层定义的变量，整个文件内的所有函数、代码都可访问               |
| **B**   | Built-in（内置作用域） | Python 内置的函数 / 对象（如len、print、str），所有文件都可直接访问 |

默认情况下，函数内部只能读取全局变量，无法直接修改；嵌套函数同理。需要通过`关键字`声明，才能修改外层作用域的变量。

- **global**：在函数内部修改全局作用域的变量时使用
    ```python
    # global：修改全局变量
    count = 0  # 全局变量

    # 定义一个函数
    def add_count():
        global count  # 声明：此处使用全局的count变量
        count += 1    # 修改全局变量

    add_count()
    print(count)  # 输出 1
    ```

- **nonlocal**：在嵌套函数中，修改外层函数（非全局）的变量时使用，不可用于全局变量
    ```python
    # nonlocal：修改嵌套外层变量
    def outer():
        num = 10  # 外层函数变量（嵌套作用域）
        def inner():
            nonlocal num  # 声明：此处使用外层函数的num变量
            num += 5
            print(num)
        inner()

    outer()  # 输出 15
    ```

### 可变对象

Python 对象分为`不可变对象`和`可变对象`，两者的赋值行为完全不同：

- **不可变对象**：`int、str、float、tuple（元组）、bool`，对象本身不可修改，`修改变量只会指向新对象`，不会影响其他绑定该对象的变量。
    ```python
    # 不可变对象示例
    a = 10
    b = a
    a = 20
    print(b)  # 输出 10，b仍指向原对象10，不受影响
    ```

- **可变对象**：`list、dict、set`，对象本身可修改，多个变量绑定同一个对象时，修改其中一个，所有变量都会受影响。
    ```python
    # 可变对象示例
    list1 = [1,2,3]
    list2 = list1  # list2和list1绑定同一个列表对象
    list2.append(4)
    print(list1)  # 输出 [1,2,3,4]，list1同步被修改
    ```

如果想让 list1 不受 list2 的影响，可以通过浅拷贝 `list2 = list1.copy()` / `list2 = list1[:]`。当然对于复杂嵌套对象用深拷贝 `import copy;` `list2 = copy.deepcopy(list1)`。

通过 `id(变量)` 可以获取该变量的引用地址：
```python
a = 20
print(id(a)) # 输出 140710305695448，每次打印值会改变
```
