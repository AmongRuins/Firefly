## 函数

函数是使用 `def` 关键字定义、封装了独立功能的代码块，可在需要时重复调用。

核心优势：大幅减少重复代码、降低代码冗余，同时提升代码的可读性与开发效率。

1. 形参与实参

    - 形参：函数定义时括号内声明的参数，无具体数值，仅起到占位作用，用于接收调用时传入的数据。

    - 实参：函数调用时括号内传入的具体数据值，会传递给对应的形参，供函数内部使用。

2. return 语句：用于`终止函数的执行`，同时可将函数的执行结果返回给调用处。

    - 若 return 后未写任何数据，或函数体中完全不写 return，函数执行结束后默认返回 None；

    - 若 return 后携带具体数据，会将该数据作为函数的返回值，返回给函数调用的位置；

    - 函数一旦执行到 return 语句，会立即终止执行，后续代码不会运行。

3. 函数文档注释：在函数体的开头，使用`三引号`包裹注释内容，用于说明函数的功能、参数含义、返回值等信息。

## 可变类型与不可变类型

二者的核心区分依据：数据在内存中创建后，`不通过赋值符号 = 重新赋值，能否直接修改内存中的数据内容`。

- **不可变类型**：数据创建后，内存中的内容无法直接修改；若要变更数据，只能`通过重新赋值开辟新的内存空间`。典型类型：字符串、数字、元组。

- **可变类型**：数据创建后，无需重新赋值，可直接修改内存中的数据内容，且`修改前后数据的内存地址保持不变`。典型类型：列表、字典、集合。

## 变量的引用

Python 中，变量存储的`不是数据本身`，而是数据在内存中的`引用地址（内存地址）`。

- 每一个数据在内存中，都会占用一个独立的存储空间，对应唯一的内存地址。

- 执行赋值操作`变量名 = 数据`时，本质是将该数据的内存地址，引用给了对应的变量。

- `id(变量名)`函数：可查看变量所引用数据的内存地址，结果以整数形式呈现。

## 变量交换、组包与拆包

1. **变量快速交换**：Python 支持极简的变量交换语法，无需中间变量，即可直接交换两个变量的引用地址（`a, b = b, a`）

2. **组包（打包）**：将多个数据值用逗号连接，会`自动封装`为一个元组，这个过程称为组包。

    示例：`c = a, b`，执行后`变量c`的类型为元组，存储了 `a 和 b` 的值。

3. 拆包（解包）：将容器（元组、列表、集合等）中的元素，`一次性赋值给多个变量`，这个过程称为拆包。

    - 核心要求：接收数据的变量个数，必须与容器内的元素`个数完全一致`。

    - 示例：`a, b = c`，执行后会将`元组c`中的两个元素，分别赋值给`变量 a 和 b`。
