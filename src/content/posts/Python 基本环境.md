## Python 简介

Python 是一款由荷兰程序员 **吉多・范罗苏姆（Guido van Rossum）** 设计开发的`高级、解释型、通用型编程语言`。

它以 “优雅、明确、简单” 为核心设计哲学，`语法极简、可读性极强，同时兼具强大的扩展性与跨平台能力`，是目前全球`最流行、应用最广泛`的编程语言之一，常年稳居 TIOBE 编程语言排行榜前列，也是编程入门、科研、工业开发的首选语言之一。

Python 是`解释型语言`，无需预先编译，而是通过`解释器（Interpreter）` 逐行（或逐段）将源代码 “翻译” 为机器码并立即执行，不生成独立的可执行文件。其核心特点是：

- **跨平台性强**：只需有对应平台的解释器即可运行，一次编写，随处运行。

- **开发效率高**：无需编译环节，修改代码后可立即运行，调试灵活。

- **运行速度相对较慢**：逐行解释的 overhead（额外开销）导致性能通常弱于编译型语言（现代解释器通过 JIT 等技术可大幅优化）。

### 补充

**编译型语言**会先通过编译器（Compiler） 将源代码一次性编译成计算机可直接执行的机器码（或中间代码），生成独立的可执行文件（如.exe、二进制文件），之后运行时无需再编译。其核心特点是：

- **运行速度极快**：直接执行机器码，无需逐行解释，性能通常优于解释型语言。

- **跨平台性差**：编译后的可执行文件依赖特定操作系统 / 硬件架构，需针对不同平台重新编译。

- **编译周期长**：修改代码后需重新编译整个项目，调试相对繁琐。

目前很多语言融合了两者的优势，通过`即时编译`（JIT, Just-In-Time Compilation） 技术，在运行时将热点代码（频繁执行的部分）编译为机器码，兼顾开发效率与运行性能。

`Java`（先编译为字节码，运行时 JVM 通过 JIT 编译为机器码）、`C#`、`JavaScript`（V8 引擎）、`PyPy`（Python 的 JIT 实现）等。

## 环境安装

当前 Python 2 官方正式终止维护，`Python 3` 成为唯一主流版本，目前主流稳定版为 `3.10+`，持续优化性能与语法特性。

前往 [Python 官方网站](https://www.python.org/) 下载最新的`软件安装包（解释器）`即可。在刚开始安装软件，可以勾选 `Add python.exe to PATH` 将程序添加到环境变量中，这样无论在哪个路径下都可以启动 Python 程序。

![](./images/python/Snipaste_2026-04-24_23-05-57.webp)

[PyCharm](https://www.jetbrains.com/zh-cn/pycharm/) 是一款专业的 Python 集成开发环境（IDE），也是目前除 VSCode 外最主流的 Python 开发工具。它已统一为单一安装包，内置 30 天专业版全功能免费试用，到期后自动切换为社区版。

在 PyCharm 中，代码下方的不同颜色波浪线代表不同含义：

- **红色波浪线**：表示代码存在语法或逻辑错误，执行时会直接报错。

- **灰色波浪线**：提示代码未遵循 PEP 8 编码规范，可使用快捷键 `Ctrl+Alt+L` 一键格式化代码。

- **绿色波浪线**：表明单词拼写可能有误。
